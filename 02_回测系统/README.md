## 引擎的关键口径

- **复权记账**：用「复权份额」而不是「原始股数 × 复权价」——
  后者会把持仓价值凭空虚增（000001.SZ 的 cumadj 达 98 倍）。
- **涨跌停方向性**：一字涨停禁买、一字跌停禁卖；**反向允许**（跌停时卖盘堆积，买方反而容易成交）。
- **T+1 / 容量 / 成本**：先卖后买、参与率上限（默认 10% 当日成交额）、佣金+印花税+过户费+滑点+平方根冲击。
- 被挡下的委托**不假装成交**，逐日落库可审计。

下面是从旧总 README 搬过来的口径细节。

## 1. 复权记账（注意点 1）

**不能用「原始股数 x 复权价」记账**：`cumadj` 是累乘因子（000001.SZ 达 98 倍），
原始股数乘复权价会把持仓价值凭空虚增 98 倍。引擎改用**复权份额**记账：

```
复权份额 units = 原始股数 / cumadj_t
持仓市值 value_t = units x adj_close_t = 原始股数 x 原始价_t
买入 dv 元：units += dv / (adj_exec x (1+滑点))，现金 -= dv + 费用
NAV = 现金 + units @ adj_close_t
```

这样 NAV 天然是**全收益**口径：除权日原始价下跌、复权价连续，分红自动留在净值里，
不需要记分红流水，也不会在除权日产生假亏损。

配套的三处细节：

- **复权因子必须先去噪**：非调整日的相对抖动只有 1e-6~1e-5（浮点噪声），真实分红送转才
  >1e-4。直接 `pct_change()` 会在 **880,546 格**上凭空造出非零变化（真事件只有 26,295 格，
  **假事件是真事件的 33 倍**）。`md.cumadj_clean` 去噪后噪声归零、真事件一格不少。
- **涨跌停基准价用除权参考价**：除权日的涨跌幅以除权参考价为基准，而非原始昨收
  （`md.prev_ref`）。
- **四舍五入必须用交易所口径**：numpy/pandas 的 `round` 是四舍六入五取偶，昨收 5.75 的
  涨停价交易所算 **6.33**、pandas 算 6.32，凭空产生约 2,700 格假的「突破涨停」。
  `lib.round_tick()` 修正后降到 266 格且全部落在 `no_limit` 内。

### 不复权的代价（实测）

同一策略、同一区间，只把记账换成原始价（`Backtest(use_adjusted=False)`）：

| 策略 | 基准口径年化 | 不复权记账 | 差异 |
| --- | ---: | ---: | ---: |
| 低流动性20 | 16.33% | 13.46% | **−2.88 pp** |
| 反转5 | −5.69% | −9.32% | **−3.63 pp** |
| 动量20 | −31.37% | −33.56% | **−2.19 pp** |

**平均低估 2.9 个百分点/年** —— 除权跳空既污染信号，也污染成交价与撮合判断。

## 2. 涨跌停不可交易（注意点 2）

执行价取**次日开盘**（信号在 t 日收盘产生），逐笔检查。注意**方向性**：

| 情形 | 买入 | 卖出 | 理由 |
| --- | :---: | :---: | --- |
| 停牌（`amt = 0`） | 拒绝 | 拒绝 | 全天无成交 |
| 开盘即在涨停价 | **拒绝** | 允许 | 无卖盘，买单排不上队 |
| 一字涨停 | **拒绝** | 允许 | 全天单一价格，买不进；但卖盘能立即成交 |
| 开盘即在跌停价 | 允许 | **拒绝** | 无买盘，卖单排不上队 |
| 一字跌停 | 允许 | **拒绝** | 卖盘堆积，买方**反而容易**成交 |
| 参与率上限 | 截断 | 截断 | 单日单票 ≤ 当日成交额的 10% |
| T+1 | — | 当日买入不可卖 | 先卖后买 + 每日单次下单，结构性满足 |

被挡下的委托**不会假装成交**：在调仓执行窗口（默认 3 个交易日）内逐日重试，
窗口结束仍未成交就放弃、持仓自然漂移。**所有被挡记录都落库**，可逐笔审计。

### 忽略涨跌停的代价（实测）

| 策略 | 基准口径年化 | 忽略涨跌停/停牌 | 差异 |
| --- | ---: | ---: | ---: |
| 低流动性20 | 16.33% | 16.30% | −0.04 pp |
| 反转5 | −5.69% | −4.84% | **+0.85 pp** |
| 动量20 | −31.37% | −30.93% | **+0.44 pp** |

**平均高估 0.42 个百分点/年**。绝对幅度不大，但方向明确，而且解释了为什么
**动量策略在实盘里比回测更差**：累计有 6,493 万元委托在涨停板上买不进
（涨得好才买、涨得好就买不到）。低流动性策略反而更受**参与率上限**制约 ——
被截断的委托高达 51.2 亿元，容量约束才是它的真正瓶颈。

## 3. 其余实盘约束

| 项目 | 默认取值 |
| --- | --- |
| 佣金 | 万 2.5，单笔最低 5 元 |
| 印花税 | 卖出，2023-08-28 前千 1、之后万 5 |
| 过户费 | 万 0.1，双向 |
| 滑点 | 5 bp（单边，固定） |
| 冲击成本 | `coef x sqrt(成交额 / 当日成交额)` |
| 参与率上限 | 10% 的当日成交额 |
| 执行窗口 | 3 个交易日（被挡委托在窗口内重试） |

交易成本与参与率合计再影响 **2.8 个百分点/年**。

## 5. 波动率 + 成交量低频策略

`core/factors.py` 提供 13 个因子，全部**逐日现算、只用 t 日及之前的数据**（有单测把 t 之后
的数据整段置 NaN，断言 t 日因子值一字不变）。

| 族 | 因子 | 含义 |
| --- | --- | --- |
| 波动率 | `ivol` | **特质波动率**：对等权市场收益做市场模型回归，取残差标准差 |
| 波动率 | `dvol` | 下行波动（半偏差，只看负收益） |
| 波动率 | `maxdd` | 区间最大回撤 `max(1 - close / cummax(close))` |
| 波动率 | `skew` / `kurt` | 收益偏度 / 超额峰度 |
| 波动率 | `vol_trend` | 波动率变化：短窗波动 / 长窗波动 − 1 |
| 波动率 | `vol_of_vol` | 波动率的不稳定性（滚动波动的标准差） |
| 波动率 | `beta` | 市场模型 beta |
| 成交量 | `amt_trend` | 量能放大：短窗均额 / 长窗均额 − 1 |
| 成交量 | `amt_cv` | 成交量变异系数 |
| 成交量 | `amihud` | Amihud 非流动性 `mean(\|r\| / amt)` |
| 成交量 | `trade_size` | 单笔均额 `amt / num_trades`（机构参与度代理） |
| 成交量 | `pv_corr` | 量价相关 `corr(r, Δlog amt)` |

### 策略设计

- **月频调仓**（82 个调仓日），持有 50 只等权，单票上限 5%；
- **缓冲带**：老持仓只要还在前 100 名内就不卖（`buffer_mult=2`），把年换手从 23.5 倍压到 **15.8 倍**；
- **方向由样本内决定**：2021-01 ~ 2023-12 用 IC 定符号，2024 年起为样本外，**样本外不参与任何选择**；
- 执行：月末收盘出信号，次日起 3 个交易日内按目标权重在开盘成交，涨跌停/停牌不可交易。

| `trade_size` 单笔均额 | **−0.096** | −0.141 (t=−6.3) | −0.046 | 是 |
| `amihud` 非流动性 | **+0.091** | +0.116 (t=6.1) | +0.062 | 是 |
| `amt_trend` 量能放大 | −0.067 | −0.071 (t=−3.5) | −0.063 (t=−2.7) | 是 |
| `dvol` 下行波动 | −0.070 | −0.096 (t=−3.2) | −0.039 | 是 |

而非流动性越高、机构单笔越大反而越差（超大单往往是情绪高点）。

## 6. 稳健性测试

`python 02_回测系统/s05_robustness.py` 对合成策略做四类压测（详见 `out/02_回测系统/vol_report.md` §5）。

### 6.1 参数敏感性（19 组单参数扰动）

| 类别 | 结果 |
| --- | --- |
| 执行口径（开盘/收盘/中间价、执行窗口 1/3/5 日） | 年化 11.83% ~ 12.66%，**基本不敏感** |
| 参与率上限（1% / 10% / 50%） | 12.08% ~ 12.92%，**基本不敏感** |
| 持仓数（30 / 50 / 80 / 120）、缓冲带（0 / 1.5 / 2 / 3 倍） | 11.13% ~ 13.08%，**同向** |
| **交易成本（×0 / ×1 / ×3）** | **18.93% / 12.64% / 1.98%** ← 唯一真正脆弱的地方 |
| **资金规模（1 亿 / 10 亿 / 50 亿）** | **12.64% / 10.67% / 9.63%**，且持仓数从 50 膨胀到 628 |

### 6.2 成本盈亏平衡点

| 成本倍数 | ×0 | ×0.5 | ×1 | ×2 | ×3 | ×5 | ×8 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 年化收益 | 18.93% | 15.72% | 12.64% | 6.88% | 1.98% | −6.78% | −16.73% |

**盈亏平衡点在约 3.45 倍成本**。这是全篇最重要的风险提示：策略的毛收益约 19%，
成本吃掉 6.3 个百分点；能在 3.5 倍成本下依然不亏，才算有安全边际。

### 6.3 调仓频率

| 频率 | 年化收益 | 夏普 | 年换手 |
| --- | ---: | ---: | ---: |
| 月频 | **12.64%** | 0.62 | 15.8 |
| 周频 | 9.40% | 0.45 | 19.6 |
| 日频 | 11.11% | 0.54 | 21.0 |

提高频率只增加换手、不提高收益 —— **因子的半衰期在月度量级**，这是选月频的直接依据。

### 6.4 随机对照

同一股票池、同一调仓频率与持仓数，把打分换成**纯随机数**跑 30 组：

| 随机组合年化 | 中位 | 5% 分位 | 95% 分位 | 最好一组 |
| --- | ---: | ---: | ---: | ---: |
| — | 4.35% | −0.10% | 8.91% | 9.72% |

合成策略 12.64%，**高于全部 30 组随机组合**。随机组合的中位数 4.35% 就是
「同规则下的选股噪音水平」，低于基准的 8.89%（因为股票池过滤掉了最小的微盘股）。

### 6.5 引擎不变量

| 检查 | 结果 |
| --- | --- |
| 重复运行同一配置 | 完全一致（差 0） |
| **把 5451 只证券的列顺序整体打乱** | 相对差 < 1e−10（仅浮点求和顺序误差） |
| 把 t 之后的数据整段置 NaN | t 日因子值逐位不变 |
| 只改后半段信号面板 | 前半段净值逐位不变 |

第二条值得单独说：自研回测引擎最常见的隐性 bug 是「用 `argsort` 得到的下标去索引原数组」，
一旦证券顺序变了就会取错标的，**而且不会报错**，只会让净值看起来略有不同。
本引擎在这条不变量上是干净的。

### 引擎 `Backtest`

| 参数 | 说明 |
| --- | --- |
| `exec_price` | `open`（默认）/ `close` / `(o+c)/2` |
| `max_participation` | 单日单票成交额占当日成交额上限，默认 0.10 |
| `exec_window` | 调仓执行窗口（交易日），默认 3；`None` = 持续跟踪 |
| `gross_limit` | 总仓位上限，默认 0.98 |
| `use_adjusted` / `enforce_limits` | **仅用于对照实验**，生产回测保持 `True` |
