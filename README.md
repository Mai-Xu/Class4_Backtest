# Class4 回测 · 全流程量化项目

「当代量化交易系统原理与实现」第四节。**四项工作 + 一份独立核验**，每项工作一个文件夹，
每项工作有自己的 README；所有产物统一在 `out/<工作名>/` 下，按工作分开，不再混在一起。

仓库：<https://github.com/Mai-Xu/Class4_Backtest>（`feathers/` 不进库，约 226 MB）

## 快速开始

所有脚本都从**项目根目录**运行（脚本内部自带 `sys.path` 引导，在任意 cwd 也能跑），
产物自动落到 `out/<对应工作>/`。

```bash
# 测试（75 项，约 30 秒）
python -m unittest discover -s tests -v

# ① 数据核验（s02 需要联网）
python 01_数据核验/s01_audit.py
python 01_数据核验/s02_external_check.py

# ② 回测系统
python 02_回测系统/s02_backtest.py
python 02_回测系统/s03_report.py
python 02_回测系统/s04_vol_volume.py
python 02_回测系统/s05_robustness.py
python 02_回测系统/s06_report.py

# ③ 因子挖掘
python 03_因子挖掘/s07_factor_lab.py      # 交互式看板
python 03_因子挖掘/s08_factor_mining.py   # 挖掘主线
python 03_因子挖掘/s09_mining_report.py   # 净值图与规模鉴定

# ④ 多因子策略（约 100 秒）
python 04_多因子策略/s10_multifactor.py
```

依赖：`pandas` / `numpy` / `pyarrow` / `matplotlib`；
`s07_factor_lab.py` 另需 `plotly` / `scipy`。

## 多因子策略的关键结果

口径：非 ST 全市场 · 10 亿元 · 佣金单边万一 · 印花税万五 ·
2025-01-02 建仓 → 2026-09-30 清仓；因子方向与筛选**只用 2021-2024**。

| 组合 | 累计 | 年化 | 夏普 | 最大回撤 | 超额vs池内等权 | IR |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **MF5_ERC（主推）** | 47.37% | **25.85%** | 1.33 | −19.09% | **+7.36%** | 0.71 |
| MF6_ERC（多一条纯规模 sleeve） | 52.13% | 28.25% | 1.45 | −19.35% | +9.76% | 0.99 |
| MF5_ERC_ns（规模中性化） | 31.05% | 17.39% | 1.00 | **−13.62%** | **−1.10%** | −0.09 |
| 基准（池内等权 4,957 只） | 36.52% | 20.27% | 0.90 | −21.83% | — | — |

读这三条就够了（细节见 `04_多因子策略/README.md`）：

1. **执行层比因子层重要**：两个默认参数（净值比例形式的调仓阈值、合成后按权重截断）
   合计造成 **15 pp/年**的漏损，修完策略从 18.72% 变成 25.85%；
2. **规模中性化后超额归零**，赚的主要是小市值 / 低流动性 beta，代价换来回撤 −13.62% 与容量友好；
3. **只加 10bp 滑点 + 冲击成本，超额从 +7.36% 掉到 +1.38%**，16 倍换手是主要暴露。

## 数据与口径

- 7 个日频 Feather：`open/high/low/close/amt/num_trades/cumadj`，
  1643 个交易日 × 5451 只证券（2020-01-02 ~ 2026-10-16）。
- 价格是**未复权**成交价，复权价 = 原始价 × `cumadj`（累乘因子，最大 98 倍）。
- **复权记账**用「复权份额」而不是「原始股数 × 复权价」，否则持仓价值会凭空虚增。
- **涨跌停方向性**：一字涨停禁买、一字跌停禁卖；反向允许（跌停时卖盘堆积，买方反而容易成交）。
- **T+1 / 容量 / 成本**：先卖后买、参与率上限 10% 当日成交额、佣金 + 印花税 + 过户费 + 滑点 + 平方根冲击；
  被挡下的委托**不假装成交**，逐日落库可审计。

数据目录解析优先级（`core/lib.py` 的 `resolve_dir`）：
命令行 `--data-dir` → 环境变量 `CLASS4_DATA_DIR` / `FEATHERS_DIR` → 本项目 `feathers/` →
当前工作目录 → 逐级向上搜索 `close.feather`。**代码里没有任何本机绝对路径。**

## 已知限制

| 缺失内容 | 影响的环节 |
| --- | --- |
| 成交量、流通股本、总股本 | 真实换手率、市值加权、更准确的容量估计（现有「换手代理」实为成交额代理） |
| 行业分类、指数成分 | 行业中性化、基准对比、指数增强 |
| 每日涨跌停价、ST 标记、停牌公告 | 已用价格反推近似，无法 100% 还原 |
| 无 VWAP、无分钟/逐笔 | 成交价只能用 `open`/`close` 近似，无法模拟盘中排队与部分成交 |
| `num_trades` 最后一日整行为空 | 涉及成交笔数的因子在该日断点（本项目回测区间到 2026-09-30，不受影响） |
| 证券池随时间增长（3,740 → 5,216） | 必须用动态池，固定池有明显前视偏差 |

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `core/lib.py` | 数据层：复权、停牌、一字板、涨跌停、动态股票池、交易日历 |
| `core/engine.py` | 回测引擎：目标权重驱动 + 逐日撮合（T+1 / 涨跌停 / 参与率 / 成本 / 执行窗口） |
| `core/strategies.py` | 策略基类（缓冲带选股）+ 内置策略 + 因子面板构建 |
| `core/factors.py` | 13 个内置因子（波动率族 + 成交量族，`factor_zoo` 的早期版本） |
| `core/metrics.py` | 绩效、超额、分年度、执行质量 |
| `factor_zoo/` | 70 个低频因子（5 大类）+ 共享上下文 + 因果性校验器 + 面板缓存 |
| `tests/` | 75 项单元测试，含 5 条引擎**逐位恒等式** |

> `core/factors.py` 的 13 个因子是 `factor_zoo/` 70 个因子的子集（早期实现），
> 两条线并存：`02_回测系统/s04~s06` 用 13 因子，`03_因子挖掘` 与 `04_多因子策略` 用 70 因子。
