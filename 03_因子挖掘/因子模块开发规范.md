# 因子模块开发规范（factor_zoo 扩展包）

> 本文件是 subagent 写因子模块前**必须完整读完**的接口契约。目标：用「OHLC + 成交额 + 成交笔数 + 复权因子」
> 把 A 股全市场可挖的因子尽量铺满，供下游「多因子打分选股程序」直接调用。

## 0. 交付物

在 `factor_zoo/` 下**新建且只新建你被指派的那个模块文件**（例如 `factor_zoo/reversal.py`），
模块内暴露字典 `FACTORS`。不要改 `registry.py`、不要改别人的模块、不要新建其它文件。

## 1. 硬性契约（违反任何一条该因子会被主线丢弃）

1. 文件位置 `factor_zoo/<module>.py`，UTF-8。只允许 `import numpy as np` 与 `from .ctx import Ctx`。
   **不要 import pandas、不要 import core.***
2. 暴露 `FACTORS: dict[str, dict]`：

   ```python
   FACTORS = {
       "rev_ret5": dict(func=lambda t, md, C: _ret(t, C, 5),
                        desc="过去5日复权收益(短期反转)", direction=-1),
   }
   ```

   - key 必须带本模块前缀，且**不能与已有 70 个因子重名**（见 §3）。
   - `direction` 是先验方向：`+1` = 值越大越好（买高值），`-1` = 值越小越好（买低值）。
     最终方向由样本内 IC 决定，先验只用于报告，但**必须诚实填写**。
   - `desc` 用中文，一句话说清口径（窗口、单位、是否取负）。
3. 函数签名固定：`fn(t: int, md, C: Ctx) -> np.ndarray`，返回 shape=`(C.k,)` 的 `float64` 一维数组。
4. **因果性**：只能使用 `C` 中下标 `<= t` 的行。`registry.check_one` 会把所有数组截到 `[:t+1]`
   再算一遍并逐位比对，任何用到未来的写法（含 `.shift(-1)`、全样本 mean/std、未来窗口）都会被判 FAIL。
   允许使用 `md`（MarketData）读**静态**信息（如 `md.dates`、`md.symbols`），但**只能取 `md.dates[t]` 这一个时点**。
5. **不许返回 ±inf**；无法计算的位置返回 `np.nan`。出口统一过：

   ```python
   def _fin(x):
       x = np.asarray(x, dtype="float64")
       return np.where(np.isfinite(x), x, np.nan)
   ```
6. 不许抛异常：全 NaN 列、除零、空窗口、窗口长于样本都必须安静地返回 NaN。
7. **不要做横截面标准化**（除 §5.9 交互模块明确允许外）：主线统一做 2%/98% 去极值 + z-score。
   因子请保持自身量纲的原值（IC 用秩相关，单调变换不影响）。
8. 性能：单因子单次调用目标 ≤ 50ms；最重的（筹码类）≤ 500ms。整包 300+ 因子 × 70 个日期
   要在几分钟内跑完，所以**不要写 (w,k) 上的 Python 逐股循环**，用整块 numpy 矩阵运算。
9. 允许把窗口内可复用的中间结果缓存到 **Ctx 实例属性**上，例如：

   ```python
   cache = C.__dict__.setdefault("_risk2_cache", {})
   if w not in cache: cache[w] = _compute(...)
   ```

   **禁止模块级 / 全局缓存**（会让因果性检验失效）。`Ctx.truncated(t)` 造出的是全新对象，缓存天然隔离。
10. 只读，不要就地修改 `C.R / C.C / C.A ...`（截断检验共用同一份数组）。

## 2. 数据字典（`factor_zoo/ctx.py` 已提供）

| 属性 | 形状 | 含义 |
| --- | --- | --- |
| `C.n, C.k` | 标量 | 行数(交易日) × 列数(证券，5451) |
| `C.R` | (n,k) | **复权**日收益；停牌日=0，未上市/退市=NaN，新股首日跳幅保留 |
| `C.C` | (n,k) | 复权收盘价 |
| `C.ADJ_O / C.ADJ_H / C.ADJ_L` | (n,k) | 复权开/高/低 |
| `C.RAW / C.O / C.H / C.L` | (n,k) | **未复权**价，只能用于涨跌停/一字板判断，**禁止用于收益或统计** |
| `C.A` | (n,k) | 成交额（元） |
| `C.NT` | (n,k) | 成交笔数（有零星缺口，注意 `NT>0`） |
| `C.listed` | (n,k) bool | 有报价（含停牌） |
| `C.mkt` | (n,) | 等权市场日收益（已剔除停牌/一字板），可能是 NaN |
| `C.mkt_fill` | (n,) | 上面填 0 的版本 |
| `C.VWAP_PROXY` | (n,k) | (H+L+C)/3 未复权均价代理，**不要直接用**（与 C 口径不一致） |

工具（掩码版，别用 np.nan*）：

```python
lo, W = C.sl(t, w, X)              # 取 [t-w+1, t] 窗口，返回 (起始行, (w,k))
ma = C.mean(W, ok, min_cnt)        # 掩码均值，有效数 < min_cnt 返回 NaN
sd = C.std(W, ok, min_cnt, ddof=1) # 掩码标准差
S  = C.stats(t, w, X)              # dict(W, Wc=中心化, ok, cnt, mu, var, bad, lo)，一次算全
```

约定：

- 价格类因子**一律复权口径**（`C.C / C.ADJ_O / C.ADJ_H / C.ADJ_L`）；隔夜收益 = `ADJ_O[t]/C[t-1]-1`，
  日内收益 = `C[t]/ADJ_O[t]-1`。
- 窗口最少有效样本：短窗 `min_cnt = max(3, ceil(0.6*w))`，长窗（≥120）用 `max(20, ceil(0.6*w))`。
- 数据从 2020-01-02 开始（1643 个交易日）；窗口 ≤250 日的因子在 2021 年初就有覆盖。
  **请把主窗口控制在 ≤250 日**，个别长周期因子可用 300~500 日但要说明。
- 停牌日 `C.R=0` 会把波动率低估，这是已知数据限制，按 `ok=isfinite` 处理即可。
- 每个因子的横截面标准差必须 > 0（纯常数因子会被注册表判失败）。

### 5.5 `chip.py`（前缀 ch_，约 20 个）——筹码分布代理

> 没有逐笔数据，用「过去 N 日成交额按当日典型价分箱」近似筹码分布。
> **必须这样做，否则太慢**：价格箱设计成**相对于当日收盘价的固定对数网格**
> （例如 64 箱覆盖 `[0.5, 2.0] × C[t]`），对 63 条箱边界 `b` 用矩阵运算求
> `w_b = sum(A * (typ < b), axis=0)`（掩码版），差分得到箱权重与累计权重。
> 单次调用 ≤ 0.5s；中间结果按 `t` 缓存在 `C.__dict__`（**禁止模块级缓存**）。
