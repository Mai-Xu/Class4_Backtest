## 1. 一句话结论

1. **因子库 390 个**（15 个模块 / 7 大家族），全部通过形状、覆盖率、**因果性**校验；302 个样本内 |IC20| ≥ 0.02，330 个 |ICIR| ≥ 0.5，240 个冗余簇；样本外与样本内同向且 |IC20| ≥ 0.02 的有 **307 个**。
2. **信号是真的**：复合打分样本外五分位年化 Q1 **+3.9%** → Q5 **+22.3%**（Q5−Q1 = **+18.4pp**），样本内 Q5−Q1 = **+29.9pp**，池内等权同期 5.6% / 17.5%。
3. **多头端的 α 主要来自「剔除最差尾部」而不是「集中买头部」**：纸面 OOS 年化 N=50 → 18.2%、N=100 → 19.0%、N=400 → 21.2%、**N=1700 → 22.9%**、N=2500 → 22.5%；N=100 的**真实回测**只有 14.8%（参与率上限挡掉大量委托）。因此主推**打分前 40%（约 1700 只）等权**。
4. **主推组合（树模型打分 ML1700）**：年化 **29.38%**、夏普 **1.34**、最大回撤 −21.92%、超额 **+9.10pp**、IR **1.73**；加 10bp 滑点 + 平方根冲击后仍有 **26.66%**（超额 +6.38pp）。
5. **线性合成版（MF1700_raw，ICIR 加权）**：年化 **22.51%**、夏普 **1.21**、最大回撤 **−17.52%**、超额 +2.23pp、IR 0.26；再加 10bp 滑点就掉到 20.26%（超额 −0.02pp）。**线性版的超额经不起滑点，树模型版扛得住。**
6. **规模中性化后超额归零**（+2.23pp → +0.07pp），但回撤改善 1.9pp（−17.52% → −15.66%）—— 超额里仍有一部分是小市值/低流动性 beta。
7. **同池同持仓数的随机对照**（10 组）：年化中位 20.95%、区间 [19.53%, 22.67%]，MF1700_raw 处在第 90 百分位；随机组夏普中位 0.97、回撤中位 −20.2%。

## 4. 评价口径

- **网格**：2021-01 ~ 2026-09 每月最后一个交易日（69 期）收盘出信号。
- **前视收益**：`ADJ_O[t+1+h] / ADJ_O[t+1] − 1`（h = 1/5/10/20），即**次日开盘买入、持有 h 日后开盘卖出**的可成交口径。
- **样本划分**：训练/定方向 = 2021-01 ~ 2024-12（48 期）；样本外 = 2025-01 ~ 2026-09（21 期）。树模型的训练集只到 **2024-11-29**（保证标签已实现），预测从 2024-12-31 起，回测同样在 2025-01-02 建仓。
- **因子筛选**：`coverage ≥ 0.6 & |IC20| ≥ 0.02 & |ICIR| ≥ 0.5`，再用平均横截面相关层次聚类（|ρ| > 0.85 合并），每簇留 |ICIR| 最大的代表 → **165 个入选**。
- **合成**：家族内按 |ICIR| 加权（当日横截面秩 z），家族间按家族分数的**样本内 ICIR** 加权（单家族上限 45%）→ 总分再做横截面秩 z。
- **回测引擎**：次日开盘成交、T+1、涨跌停/一字板/停牌挡单、参与率上限 10%、用户指定佣金与印花税，逐日持仓与委托落库。
- **年化口径**：按 252 交易日折算（425 个交易日 = 1.6865 年）；若按自然日折算，MF1700_raw 的年化为 21.53% 而非 22.51%。

## 6. 关键结论与局限

**结论**

1. 从 OHLC + 成交额 + 成交笔数 + 复权因子里能挖出**样本外仍然有效**的横截面信号（复合打分 OOS 五分位单调，Q5−Q1 = +18.4pp/年；307/390 个因子样本外同向）。
2. **多头端的 α 主要来自「避开最差的一档」**：打分最高的 2%~5% 与池内等权几乎无差别，所以 10 亿资金下正确的用法是**宽持仓 + 打分倾斜**（本报告主推约 1700 只），而不是集中 top-100（真实回测只有 14.8%，还被参与率上限挡掉大量委托）。
3. **执行摩擦与成本是主要漏损**：指定费用只花 0.38%/年，但 10bp 滑点 + 冲击就让线性版的超额从 +2.23pp 变成 −0.02pp；换手 10x 是核心暴露。树模型版换手相当但超额更厚，能扛住同样的滑点（+6.38pp）。
4. **规模/流动性 beta 仍是收益来源之一**：规模中性化后超额从 +2.23pp 掉到 +0.07pp，但回撤改善 1.9pp。是否中性化取决于是否接受这个 beta。

**局限（必须一起读）**

- 数据只有日频 OHLC + 成交额 + 成交笔数 + 复权因子：**没有成交量、流通股本、市值、行业、ST 标记、指数成分、逐笔/分钟数据**。换手率是成交额代理、VWAP 是典型价代理、筹码分布是成交额分箱代理、大单/机构行为是单笔均额代理。
- ST 用「5% 涨跌幅 + 违规法」反推，全样本只识别出 2 只（数据源基本已剔除 ST），**非 ST 过滤是近似**。
- 涨跌停价按「板块先验 + 时代规则」反推；停牌、复牌、退市整理日按 `amt==0` / 异常涨幅近似；无法 100% 还原交易所逐日价格。
- 样本外只有 **21 个月**，年化差异的标准误约 ±4pp；随机对照 10 组也说明「同池随机选股」分布很宽。**不要把 +9.1pp 或 +2.2pp 当成精确估计。**
- 阈值（|IC| ≥ 0.02、|ICIR| ≥ 0.5、聚类 0.85、N=1700、buffer=1.0）由研究者选择，存在选择性偏差；树模型只用一次切分、没有滚动重训，也没做行业/市值中性化。
- 年化用 252 交易日折算；按自然日折算会低约 1pp。
