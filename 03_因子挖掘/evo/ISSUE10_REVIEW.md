# Issue #10 阅读与改进记录

## 1. 老师的指导（PPT 与课堂实验）

老师这一讲的核心不是“让 LLM 随便生成因子”，而是：

1. **改进对象要分清**：程序 / Harness / 模型参数，三者不是一回事。
2. **外部评价决定保留**：模型提出修改，运行结果决定是否保留。
3. **评价必须可靠**：金融收益噪声大，历史高分不能替代独立检验。
4. **固定预算比较**：基线组、Harness 组、训练组必须用同一批任务、同一总预算比较。
5. **保留多样性**：高分结构提供起点，但不同结构要留在程序库中，避免单一路线。
6. **多次搜索有选择偏差**：候选越多，历史最高分越高；应使用独立测试、冻结和适当的统计校正。
7. **记录全部尝试**：不只报告最优项，要保留失败、拒绝原因、预算和成本。

对应到本次实践：不能把“多跑几个组合后的最高分”直接叫自我进化；必须同时报告同预算随机搜索、验证集、冻结后的独立结果和失败台账。

## 2. 其他同学的做法

- 安全 DSL，不允许任意 Python；
- 训练 / 开发验证 / 封存测试严格分段；

### gry1024：LLM 反事实 + 池增量

- 删除法找低贡献父因子；
- LLM 把父因子拆成子树，提出局部替换；

- 候选通过相关性 ≤0.75、池增量 >0 才入池；
- 把本轮接受/拒绝结果写回下一轮提示词，形成搜索策略记忆。

可借鉴：**反事实拆结构、池增量、把失败写回搜索策略。**

不足：评估仍是样本内，成本是换手代理，尚未接入真实撮合和独立 OOS。

### tyoukan1994：严格冻结与全量留痕

## 3. 我们对 Class4 实验的改进

### V1（已完成）

- 239 个聚类代表，197 个训练可用因子；
- 2021–2022 训练，2023–2024 验证，2025–2026 冻结后一次 OOS；
- 59 个进化候选 + 59 个同预算随机候选；
- 8 因子主候选 OOS：年化 24.00%，夏普 1.22，最大回撤 −19.47%。

### V2（补审计）

新增：

- 5 个随机种子；
- 每个种子 59 个进化 + 59 个同预算随机；
- Bonferroni 多重检验；
- 3-block bootstrap 95% 区间；
- 失败原因分类；
- 冻结主候选的 0/10/20/30bp 滑点敏感性。

关键结果：

- 5 个种子中，**随机搜索在验证集上全部优于进化组合**；
- 进化验证 ICIR 约 2.58–2.74，随机约 2.72–3.40；
- 进化 Bonferroni 校正后 p 约 0.046–0.080，随机约 0.004–0.049；
- 说明当前“进化”没有稳定超过同预算随机搜索；
- 冻结主候选在 30bp 滑点下年化约 20.5%、夏普约 1.04，成本敏感性尚可，但这不能证明进化有效。

### V3（把验证放进搜索内部）

新增：

- 2021H1–2022H1 作为 inner train；
- 2022H2 作为 inner holdout；
- 适应度加入 inner holdout ICIR、retention、gap penalty、复杂度和换手惩罚；
- 2023–2024 仍为 outer validation；
- 2025–2026 不在 V3 中使用，因为 V1 已经消费过，不能再冒充盲测。

结果：

- 5 个种子中，随机搜索在 combined 上 **5/5** 胜出；
- 平均 combined 差值约 **−0.474**；
- 说明“在组合层加 inner holdout”仍不足以让进化稳定超过随机。


## 3.5 公式级补充实验（`03_因子挖掘/evo_formula/`）

在组合层 V2/V3 被随机搜索压制后，又补做了公式树级搜索：

- 53 个因果时序基元；
- 节点算子：`neg / abs / square / rank / z / add / sub / mul / div`；
- 最大 9 节点、深度 4；
- 135 个进化公式 + 135 个同预算随机公式；
- 训练 2021–2022，验证 2023–2024，冻结后看 2025–2026。

验证段主公式 `-(amtlog60 + max5d20)`：

- 训练方向调整后 ICIR 4.52；
- 验证方向调整后 ICIR 2.60；
- 同预算随机最佳 2.44；
- 验证段略优，但优势不大。

OOS 暴露了真正的问题：

- 训练段方向为负，冻结时取 `direction=-1`；
- OOS 方向调整后的 IC 变成 −0.1247、ICIR −2.11，**方向翻转**；
- 虽然 `fastsim` 仍显示 25.82% 年化和 1.33 夏普，但这不能证明公式有 alpha；
- 同预算随机公式也出现方向翻转，随机年化 27.80%、夏普 1.32；
- `neg(ret5)` 方向未翻转，但 IC 弱且换手 16.68x。

结论：

1. 公式级搜索比“选因子 + 调权重”更接近真正的程序搜索；
2. 但这次仍然没有通过 OOS 方向稳定性检验；
3. 随机公式同样能做到高回测年化，说明宽基 beta/持仓结构/风格暴露可能主导结果；
4. **OOS 已经被 V1 和公式实验先后使用，不能把第二次称为新的独立盲测。** 后续必须用新的未来数据或外部隔离数据。

## 4. 结论

**当前失败的不是“因子完全无效”，而是“因子组合层的进化没有证明自己优于同预算随机搜索”。**

真正需要改进的是表示和搜索对象：

1. 从“选因子 + 调权重”升级为“公式级 genome”：算子、窗口、条件门控、分母、秩变换；
2. 加入反事实拆解和池增量，判断一个修改是否真的改善组合；
3. 把接受/拒绝原因写回下一轮搜索策略；
4. 使用嵌套 walk-forward，而不是固定一次 2021–2022；
5. 保留独立未来数据；已经看过的 2025–2026 不能再当第二次盲测；
6. 报告全部候选、预算、失败原因和成本敏感性。
