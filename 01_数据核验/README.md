# 01_数据核验

本目录只做**一件事**：证明 `../feathers/` 的 7 个日频矩阵不仅「自洽」，而且「正确」。
回测与因子挖掘是另外两项工作（`../002_回测系统/`、`../003_因子挖掘/`），共用 `../core/lib.py` 数据层。

## 三层验证

| 层级 | 手段 | 入口 | 结论 |
| --- | --- | --- | --- |
| **结构自洽** | 29 项单元测试 | [`../tests/test_lib.py`](../tests/test_lib.py) | 全部通过 |
| **内部一致** | 掩码对齐 / 复权去噪 / 涨跌停逐格违约 / 极端日对照真实事件 | `s01_audit.py` | 见 `out/01_数据核验/data_audit.md` |
| **外部真值** | 与公开行情源逐格比对 | `s02_external_check.py` | 见 `out/01_数据核验/external_check.md` |

## 运行

在**项目根目录**运行（脚本自带 `sys.path` 引导）：

```bash
python 01_数据核验/s01_audit.py                        # 数据体检（约 17 秒）
python 01_数据核验/s02_external_check.py               # 外部比对（联网，约 30 秒）
python 01_数据核验/s02_external_check.py --sample 12 --random 18
python -m unittest tests.test_lib -v                       # 29 项数据层测试
```

> 产物统一落 `../out/01_数据核验/`（与其它三项工作同一套约定）。
> 脚本在启动时把 `core.lib` 的 `FIG`/`TAB` 指向这里，所以产物不会跑到别人的目录。

依赖 `pandas` / `numpy` / `pyarrow` / `matplotlib`（Python 3.13）。
`s02_external_check.py` 需要联网，**回测本身不依赖网络**。

## 外部核对结果（30 只证券：12 只固定大盘股 + 18 只随机抽取）

| 核对项 | 外部来源 | 规模 | 结果 |
| --- | --- | --- | --- |
| 不复权开 / 高 / 低 / 收 | 腾讯行情日线 | 44,131 个证券日 = **176,524 格** | **逐格完全一致，最大价差 0.000000 元** |
| 成交额（`VWAP` 必落在 `[low, high]` 的数学约束） | 腾讯行情成交量 | 44,131 个证券日 | **0 越界** |
| 复权收益 | 腾讯前复权 | 640 日 x 30 只，89 个除权日 | 与外部一致；同样这些日子用**未复权**收益比会差到 **30.5%** |

## 关于 `core/lib.py`

数据层已归入**项目根目录的 `core/`**，本目录不自带副本：

- `core/engine.py` / `core/strategies.py` / `02_回测系统/s02_backtest.py` … 都
  `from core.lib import ...`；三条轨道共用同一份数据层；
- `core/lib.py` 定义项目共用的 `ROOT / FIG / TAB`（`ROOT` = 项目根）。
  本目录的脚本在**调用时**把 `FIG / TAB` 覆盖成自己的 `out/01_数据核验/`，
  因此这份核查证据与主 `out/01_数据核验/` 的大体积产物互不干扰。

本目录的脚本通过把上级目录挂进 `sys.path` 来引用它，并把 `savefig` / `savetab`
的输出重定向到本目录的 `out/01_数据核验/`，因此**两边互不干扰**。
