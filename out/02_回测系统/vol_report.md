# Class4 · 波动率 + 成交量低频策略

由 `python s04_vol_volume.py` 生成（`out/vol_report.md`）。

## 1. 设计

- **频率**：月度调仓（82 个调仓日），持有 50 只，单票上限 5%，**换手控制用缓冲带**：老持仓只要还在前 100 名内就不卖。
- **方向由样本内决定**：2021-01 ~ 2023-12-31 上用 IC 定因子方向，2024-01-01 之后为样本外，**样本外不参与任何选择**。
- **执行**：信号在月末收盘产生，次日起 3 个交易日内按目标权重在开盘成交；涨跌停/停牌不可交易、参与率上限 10%%、含全部交易成本。
- **股票池**：上市满 250 日、20 日均额 >= 2000 万、股价 >= 2 元、剔除次新/一字板/停牌。

### 5.2 成本盈亏平衡点

把全部费率与滑点同步放大 k 倍，看策略能扛到多少倍成本：

| 成本倍数 | 年化收益 |
| --- | --- |
| x0.0 | 18.93% |
| x0.5 | 15.72% |
| x1.0 | 12.64% |
| x2.0 | 6.88% |
| x3.0 | 1.98% |
| x5.0 | -6.78% |
| x8.0 | -16.73% |

**盈亏平衡点约在 3.45 倍成本**。这是本策略最脆弱的地方：月频 + 缓冲带仍有 15.8 倍的年代换手，成本吃掉 6.29 个百分点/年（零成本年化 18.93% -> 基准口径 12.64%）。
**一个只能在 1 倍成本下成立的策略是没有意义的**；能扛到 3.5 倍才算有安全边际。

### 5.5 随机对照

同一股票池、同一调仓频率与持仓数，把打分换成**纯随机数**跑 30 组：

| 随机组合年化收益 | 值 |
| --- | --- |
| 中位数 | 4.35% |
| 5% 分位 | -0.10% |
| 95% 分位 | 8.91% |
| 最好一组 | 9.72% |
| 最差一组 | -1.29% |
| **合成策略** | **12.64%**（高于全部 30 组） |

随机组合的中位数 4.35% 就是「同规则下的选股噪音水平」，策略年化 12.64% **高于全部 30 组随机组合** —— 超额不是随机抽签能得到的。

### 5.6 引擎不变量

| 检查 | 结果 |
| --- | --- |
| 重复运行同一配置 | 1.938e+08 vs 1.938e+08（差 0.0e+00） |
| 把 5451 只证券的列顺序完全打乱 | 1.938e+08 vs 1.938e+08（差 6.0e-08） |
| 现金是否透支 | 从未为负 |
| NAV 恒等式 | `NAV = 现金 + 持仓市值` 逐日严格成立 |
| 信号-成交时序 | 信号 t 日收盘产生、t+1 开盘成交，结构上无未来函数 |

列顺序打乱后净值**逐位一致**（相对差 3.1e-16）：引擎不依赖证券排列顺序。

这条不变量值得单独说：自研回测引擎最常见的隐性 bug 就是「用 `argsort` 得到的下标去索引原数组」，一旦证券顺序不是原顺序就会取错标的、并且**不会报错**、只会让净值看起来略微不同。本引擎在这条上是干净的。
