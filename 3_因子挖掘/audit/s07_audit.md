## 2. 检查点逐项核验

### 检查点 1 · 前瞻收益对齐（最关键）
**方法**：把 s07 的 `(adj.shift(-h)/adj - 1)`（h=21，L458）与 `core.lib.MarketData.ret_fwd(21)`（L377-380）全矩阵逐格比对；再用**日收益复利**独立重算 `prod_{j=1..21}(1+r_{t+j})-1` 抽样验证；最后构造"含 t 当天"的对照 `adj[t+21]/adj[t-1]-1` 看差值。

**实测**
- 全矩阵：max|s07_fwd − md.ret_fwd(21)| = **0**，单边有限格 **0 / 0**（共有 7,726,417 格）→ 两者**连 NaN 掩码都完全相同**。
- 调仓网格上：max|差| = **0**（共有 334,418 格）。
- 独立复利复算（373 组股票×日期抽样）：max|差| = **1.11e-15**（浮点）。
- 样例 `600456.SH @ 2026-05-29`：adj[t-1]=75.8507、adj[t]=72.4887、adj[t+21]=62.7174；
  `fwd = adj[t+21]/adj[t]-1 = −0.1347975`；若含当天 `adj[t+21]/adj[t-1]-1 = −0.1731473`，差 **−0.03835**（=t 当天收益 −4.43% 的贡献）。
- 因此 `fwd[t]` 是**从 t 收盘到 t+21 收盘**的收益，**不含 t 当天的收益**；而因子在 t 上只用 ≤t 的数据（见检查点 3），label 与特征不共享任何一段收益 → **不存在"用 t 当天信息预测 t→t+h"的同日污染**。
- 同一块 `fwd` 被 IC（L458）、十分层（L503/L511）、留一法（L517）、随机对照（L523）、top50 毛收益（L527）共用，方向一致（都是横截面 score[t] ↔ fwd[t]）。
- 附带口径提示（**不是未来函数**）：`fwd` 隐含"信号日收盘建仓"，而引擎在 **t+1 开盘**成交（`HG` 的 `exec_price="open"`，`exec_window=3`）。用 `open[t+1] → open[t+1+21]` 重算，合成打分 IC 仅从 0.1186 变到 **0.1196**（无实质差异），但**毛收益**差别不小，见问题 2。

**判定：通过**

### 检查点 3 · 股票池
**方法**：判断 `md.universe()` 是逐日动态还是固定；用"只用 ≤t 数据"的独立实现重算 t 日整行池子做逐格比对；检查池内是否存在未上市/已退市标的；核对 `run_deciles`（走 `PanelStrategy`）与 `decile_gross` 的域是否同一套。

**实测**
- **动态池**：`md.universe()` 逐日条件（上市满 250 日、20 日均额 ≥ 2000 万、股价 ≥ 2 元、剔除 ST 型/无涨跌幅日/一字板/停牌），池规模 0 → 中位 4101 → 末 4917，min/max = 0/5044，取值有 **867 种**；首日池与末日池交集 **0** → 绝非固定池。

- **未上市/已退市**：池内 `listed_days` 最小值 = **250**；池内"有价但无报价(NaN)"格数 = **0**；样本内停止报价/退市证券 **225 只**，它们"退市后仍出现在池里"的格数 = **0**。

### 问题 1（中）毛收益列口径与引擎口径不同且未披露，D1 出现"符号反转"
