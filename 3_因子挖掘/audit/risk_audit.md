2. **朴素重算**：完全不 import `factor_zoo.risk` 的内部函数，逐股 `for` 循环 + 教科书公式手写

6. **合成序列语义探针**：在完全构造的数据上验证代数性质（尺度等变、符号、门槛、闭式解、极端值）。

## 2. 逐条回答"易错点"清单

### 2.1 窗口端点：`[t-w+1, t]` 还是 `[t-w, t]`？是否误用 `t+1` / 负索引 / 破坏截断？

**是 `[t-w+1, t]`（含 t，共 w 行），全部 14 个因子都对；未发现 t+1、负索引或破坏截断的写法。**

证据：
- 用 `[t-w+1, t]` 的朴素实现与模块逐格一致（14 个因子 max|diff| ≤ 8.5e-14、NaN 掩码 0 处不一致）；
  若模块用的是 `[t-w, t-1]`，同一套朴素实现会差 4.81e-02（3 格掩码不一致）；用 `[t-w, t]`（多取一天）会差 1.24e-02（3 格掩码不一致）。
- `Ctx.sl` 是 `lo = max(t-w+1, 0)`、`X[lo:t+1]`，`_ivol` 里市场收益用 `C.mkt[lo:int(t)+1]`，与个股**同一个 lo**，对齐正确。
- `_vov` 的段端点 `ti = t - 20j`（j=0..5），`j` 最大 5、且 `ti < sub-1` 时提前整体返回 NaN（等价于 `t < 119` 全 NaN），
  因此 `ti` 永远不会变成负索引、也不会回绕。
- 截断破坏类写法（例如把 `np.maximum.accumulate` 作用在整张表上）不存在：`_maxdd` 的累乘最大值只在**窗口切片**内做。
- 投毒检验（t 之后全部换成噪声）14 个因子全部 **0.000e+00**；项目自带 `selfcheck risk` 24 个日期截断差 0.00e+00。

### 2.2 ddof / 是否年化 / `min_cnt` 是否会产生"用 5 个点估 250 日波动"

**ddof：`vol`/`ivol` 用 1（样本），`dvol`/`udvol` 用 0（除数 = 有效样本数 n，docstring 明写 `/n`）；是否年化：全部不年化；门槛：不存在"5 个点估 250 日"的问题。**

- 门槛表（脚本 `[4]`）：`max(floor, ceil(0.6w))` → vol60=36、vol120=72、vol250=150、ivol60=max(40,36)=40、vov 每段=max(10,12)=12。
- 2024-06-28 实测（有效列内窗口有效样本数）：`rk_vol60` min=42/60（p10=60）、`rk_vol250` min=151/250（p10=250）、
  `rk_ivol60` 配对 min=42、`rk_vov120` 最小 120 日覆盖=72 且 99.6% 的列 6 段全有效。
  "贴着门槛"（`cnt ≤ min_cnt+2`）的列数每日期只有 0~9 只（`rk_vov120` 按段计，另有 21~78 列落在 4~6 段的边界上）。
- 年化：代码里没有任何 `sqrt(252)`；`rk_vol250` 的数值是**日频**标准差（2024-06-28 全池中位 0.0283，年化应是 0.449）→ 见问题 P3（desc 措辞）。

### 2.3 特质波动率 ivol：市场收益是哪个？窗口对齐？残差自由度？有没有用 t 之后的市场收益？

**市场 = 等权 `C.mkt = md.ret_ok.mean(1)`（剔除了两端非正常交易与无涨跌幅日的等权收益，与 desc 一致）；窗口对齐正确；残差自由度 = cnt−1；没有用到 t 之后的市场收益。**

- 对齐：`C.mkt[lo:t+1]` 与 `C.R[lo:t+1]` 同一区间，配对掩码 `isfinite(R) & isfinite(mkt)`。
- 自由度：`df = max(cnt-1, 1)`，`var(m)`、`cov`、残差方差都用同一个 df；残差均值为 0（两侧都做了去均值），
  所以 `sqrt(Σres²/(n-1))` **就等于** `np.std(residuals, ddof=1)`。
  经典市场模型（`r_i = a + b·r_m + e`）的残差标准误用 n−2：整体比值 `sqrt((n−1)/(n−2)) = 1.0086`（n=60），
  实测中位相对差 **0.8584%**（脚本 [5a]）——这是口径选择而非错误，但建议在 desc 里写明（P4）。
- 泄漏：`t` 之后的数据被随机噪声替换后 ivol 逐位不变（0.000e+00，3 个日期）；
  `selfcheck` 截断差 0.00e+00；合成探针里 `r_i = r_m` 时 ivol=0.00000、`r_i = r_m + σ` 时 ivol ≈ σ（脚本 [6c]，
  σ=[0, 0.004, 0.012, 0.03] → ivol=[0, 0.00434, 0.01201, 0.02434]），说明回归与残差确实按市场模型在算。

### 2.4 偏度 / 峰度：总体还是样本口径？与声明是否一致？

**都是总体（有偏）口径，与 desc 声明的公式一致；但与 pandas/scipy 默认的偏差校正口径有差别。**

- 代码：`m2=Σz²/n, m3=Σz³/n, m4=Σz⁴/n`（除以 n，不是 n−1），`g1=m3/m2^1.5`、`g2=m4/m2²−3`，与 desc 字符串完全对应。
- 与偏差校正口径（`G1=g1·√(n(n−1))/(n−2)`，`G2=((n+1)g2+6)(n−1)/((n−2)(n−3))`）的中位相对差：
  skew60 **2.58%**、skew250 **0.60%**、kurt60 **14.90%**、kurt250 **2.87%**（脚本 [5b]）。
  w=60 时 n 最小可到 36，偏差校正因子较大，所以 kurt 差异明显 → 若与其他库/论文对齐，需注意口径。

### 2.5 最大回撤：是否 ≥0？"区间内"还是"截至 t"？

**≥0；是"区间内"（cummax 从窗口第一行重新起算）。**

- 值域：60 日 `[0.000000, 0.979726]`、250 日 `[0.000000, 0.982039]`，负值 0 个（脚本 [5d]）；全平价格列 = 0；价格跌到 ~0 时为 0.999999 < 1。
- 与"截至 t 全历史 cummax"口径对比：24133 / 28191 个列-日期不同，最大差 **0.855**（脚本 [5c]）；
  合成探针里把崩盘放在 60 日窗口之外，模块 maxdd60 = 0.000 而全历史口径 = 0.500（脚本 [6e]）。
  → 证实模块就是 desc 说的"**区间**最大回撤"，不是"距历史高点的回撤"。

### 2.6 除法 / 取对数产生 ±inf？停牌日与上市前 NaN 怎么处理？

**无 log；除零处都有保护；45.8 万格输出里 inf = 0；上市前 NaN 的处理完全由声明门槛解释；停牌日的处理与模块 docstring 的表述不符（见 P1）。**

- inf 扫描：6 日期 × 14 因子 = 457884 格，**inf 格数 = 0**，NaN 93157 格（脚本 [5e]）。
- 极端构造：收益里塞 `1e300`（平方溢出成 inf）→ 14 个因子 inf = 0，`vol60` 变成 NaN（`_fin` 收敛）；
  价格近乎归零 → maxdd = 0.999999（脚本 [6h]）；全平价格 → vol=0、dvol=0、maxdd=0、udvol/skew/vr=NaN（NaN 由 `up ≤ 1e-12` / `m2 ≤ 1e-12` / `vl ≤ 1e-12` 保护，符合预期）。
- 上市前（真·未上市，窗口内无任何历史报价）的列：14 个因子**全部 NaN**，0 处例外（脚本 [7]）；
  某因子出现非 NaN 的列，都是"t 日无报价但窗口内仍有历史数据"的退市股（因子取的是窗口内数据，属预期）。
- NaN 政策核查（脚本 [4b]）：vol60 / vol250 / ivol60 / vov120 的 NaN 位置与"门槛判定"逐格一致，**未解释的 NaN/非 NaN = 0**。
- **停牌日不是 NaN**：停牌格 23229 个，其中 23182 个（99.9%）的 `C.R` 恰好等于 0（另有 22 个是 NaN）。
  也就是说停牌日**计入**波动率窗口、且贡献 0 收益——这与模块头部约定里写的"（停牌、上市不足等自然缺失）"矛盾（P1）。

### 2.7 direction 声称方向与实际数值方向是否一致？

**一致（14 个因子 direction 全为 −1 = 买低值；它们的数值都是"风险越大值越大"，合成探针给出决定性证据）。**

- 尺度探针：收益 ×2 → `vol60` 比值 = 2.000000000、`dvol60` 比值 = 2.000000000；`udvol60`/`skew60` 不变（差 0.00e+00）。
- 符号探针：收益取负 → `skew60` 精确反号（max|g+g'| = 0.00e+00）、`kurt60` 不变、`vol60` 不变、`udvol60 × udvol60' = 1`（偏离 1.11e-16）。
- 结构探针：`r_i = r_m + σ_i` → ivol 随 σ 单调（0 / 0.00434 / 0.01201 / 0.02434）；价格 100→110→99 → maxdd = 0.100000000（闭式 1−99/110）。
- 横截面 Spearman ρ(因子, rk_vol60)（2024-06-28）：vol120 +0.916、vol250 +0.839、ivol60 +0.810、dvol60 +0.932、maxdd60 +0.649、maxdd250 +0.668、vr60250 +0.477、vov120 +0.715；
  udvol60 −0.109、skew60 +0.125、kurt60 +0.173 属于"与总波动不同维度的风险度量"，方向本身仍与 desc 一致。
- 注：`registry.py` 也声明 `direction` 只是先验方向，最终方向由样本内 IC 决定。

## 3. 发现的真实问题（按严重度排序，均可复现）

> 结论先行：**没有发现数值错误、没有发现未来函数、没有任何 ±inf 泄漏**；
> 14 个因子在 6 个日期上与自己手写的朴素实现在浮点精度内逐格一致（含 NaN 掩码）。
> 下面 4 条是真实存在但性质分别是"文档与数据事实不符 / 因子构造口径 / 文档措辞 / 口径待明确"的问题。

### P1（文档错误 + 口径未声明，中等）停牌日按 0 收益计入波动窗口，但模块头部把停牌列为"自然缺失"

- 位置：`factor_zoo/risk.py` 第 16 行 `- 每个窗口要求有效样本 >= max(floor, 0.6 * w)，不足即 NaN（停牌、上市不足等自然缺失）`。
- 数据事实：停牌格 23229 个 = **23182 个 `C.R` 恰好 = 0**（`R = adj_close/adj_close.shift(1)-1`，停牌用前收盘携程）
  + 25 个"停牌期间除权、复权因子跳升"的非零收益 + 22 个 NaN。所以停牌既不产生 NaN、也不减少 `cnt`，
  而是作为 0 收益**进入** vol / ivol / dvol / udvol / skew / kurt / maxdd / vov 的窗口。
  （另核：`close` 与 `amt` 的 NaN 掩码 0 处不同，`amt > 0` 可以直接当 traded 掩码用。）
- 后果（有数字）：窗内停牌越多 → 波动被拉得越低。2025-06-30 的 `300280.SZ` 在 60 日窗内停牌 **60/60 天**，
  `rk_vol60 = 0.000000`，位于全市场 **0.00% 分位**（即"最安全的低波股"）。2020-03-31 有 12 只、2023-07-31 有 18 只
  "窗内停牌 ≥30 天"的股票。实际股票池（`universe()` 默认要求当日有成交 + 20 日均额 ≥2000 万）会挡掉大部分极端样本：
  2024-06-28 池内仅 5 只"窗内停牌 6~20 天"，其 `rk_vol60` 分位中位 34.6%（低于 50%，方向与预期一致）。
- 修正建议：① 文档改为"停牌日收益记为 0、计入窗口"；② 若要按"真实交易日"估波动，用 `C.A > 0`（成交额，与 close 的 NaN 掩码一致）当 traded 掩码

### P2（因子构造口径，中等）无涨跌幅日（新股/复牌，单日 |R| 最高 4.884）进入 `rk_vol*` 窗口，把波动率放大到 10 倍量级

- 机制：`C.R = md.ret`（持仓收益口径，**不剔除 `no_limit`**），而 `universe()` 的 `exclude_no_limit` 只屏蔽"当天"，
  不屏蔽之后 250 天。于是新股上市前 5 日 / 复牌日的巨幅收益会留在 `rk_vol250` 窗口里。
- 数字：全样本 `max|R| = 4.8844`（2022-08-22，`000670.SZ`，`no_limit=True`；`no_limit` 格 7179 个，其中 |R|>0.5 的 104 个）。
  2023-07-31 股票池内 `000670.SZ` 的 250 日窗含 1 个 `no_limit` 日 → `rk_vol250 = 0.3112`，
  而池内中位仅 0.0251（**12.4 倍**）；各日期池内"窗含 no_limit 日"的股票 2~8 只，
  其中位 vol250 是池内其余股票的 1.3~6.9 倍（脚本 [7]）。
- 后果：这批刚满 250 日上市门槛的股票被系统性推到"高波"一侧 → 低波多头不会买它们（机会损失），
  且同一时点上"波动率"在截面上不再可比。
- 修正建议：波动/回撤/偏峰窗口内屏蔽 `no_limit` 日（或至少对单日收益 winsorize）；同样需要给 `Ctx` 增加该掩码。
- 最小复现：

### P3（文档措辞，低）`rk_vol250` 的 desc 写"（年度已实现波动）"，但代码不年化

- 值是**日频**标准差（2024-06-28 全池中位 0.0283；年化应为 0.0283×√252 ≈ 0.449）。quant 语境里"年度已实现波动"通常指年化波动，容易被误读成 scale 差 15.9 倍。
- 建议 desc 改为"过去 250 日复权日收益标准差（日频，未年化）"。

### P4（口径待明确，低）ivol 残差自由度用 n−1，而不是经典市场模型的 n−2

- 现状：`df = max(cnt-1, 1)`，等价于 `np.std(residuals, ddof=1)`（残差均值为 0）；desc 只说"取残差标准差"，没写自由度。
- 影响：与 OLS 残差标准误口径整体差 `1/sqrt((n-1)/(n-2))`，n=60 时 **+0.86%**（实测中位相对差 0.8584%，脚本 [5a]）。
  这是一个**近似全局的尺度差**，对横截面排序影响很小（不同股票的 n 略有差异会引入 <0.5% 的排序扰动），但与其他库/论文对齐时需注意。
- 建议：desc 注明"残差标准差（ddof=1）"。

### P5（口径可争议，低，实测无影响）`rk_vov120` 的"0.6 门槛"是按段数而不是按有效日数

- 现状：模块级约定写"每个窗口要求有效样本 ≥ max(floor, 0.6×w)"；vov 实际是"每段 ≥12/20 日（=0.6×20 ✔）+ 6 段中至少 4 段有效（4/6=66.7%，由 `max(2, 0.6×6)=3.6` 向上取整而来）"。
  按 120 日窗口解读，理论下限是 4×12=48 日（40%），低于 0.6×120=72 日。
- 实测：6 个日期里 **没有任何一列**是"段数够但 120 日有效日数 <72"的；有效 vov 列的 120 日有效日数最小值 = 72、中位 = 120；
  2024-06-28 只有 21 列（0.41%）是 4~5 段（其余 5085 列 6 段全有效）。所以该差异**目前只是文档口径差异，没有实际影响**；
  若日后数据缺口变多，建议把门槛直接写成"窗口有效日数 ≥ 0.6×120"。

### P6（提示，不是错误）skew/kurt 用总体口径，与 pandas/scipy 默认不同

- 见 2.4：kurt60 与偏差校正版的中位相对差可达 14.9%。desc 已写明 `m4/m2^2-3`，所以判定"与声明一致"；
  只是提醒：任何拿 `scipy.stats.kurtosis` / `pandas.Series.kurt` 做基准的复核脚本都会看到系统性差异。
